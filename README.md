# Taxi Driver Game

Браузерная игра с видом сверху, в которой игрок работает водителем такси.

## Возможности

- управление автомобилем с помощью `WASD`;
- сигнал по клавише `Space`;
- пассажиры, дорожное движение, пешеходы и животные;
- 3 жизни, штрафы за столкновения и награды за безопасные поездки;
- гараж с улучшениями скорости, управляемости, цвета и стиля машины;
- 5 районов с разным оформлением;
- городские события с полицией, пожарной службой и скорой помощью;
- поддержка экранных кнопок на мобильных устройствах.

## Запуск

Скачайте репозиторий и откройте `index.html` в современном браузере. Сервер и установка зависимостей не требуются.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` / `S` | Газ / задний ход |
| `A` / `D` | Поворот |
| `Space` | Сигнал |
| `G` | Гараж |
